# Kali Applications Drop-Down Menu Entries (`.desktop` Files)

All base security tools and custom Caido/ZAP lab wrapper commands are registered in both:
- System-wide menu directory: `/usr/share/applications/`
- User menu directory: `/home/kali/.local/share/applications/`
